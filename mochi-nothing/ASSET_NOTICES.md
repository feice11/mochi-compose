# Firmware asset provenance

This optional local module contains resources collected from Nothing Phone (3), Nothing OS 4.1, build `Metroid_B4.1-260814-1733`. It is separate from `mochi-compose`; the base library does not depend on it. No Maven publication is configured for this module.

- Firmware package: https://android.googleapis.com/packages/ota-api/package/1825643456d6973c5ea22aff7c29d871cc071c04.zip
- Inventory and extraction evidence: `artifacts/nothing-resource-research/` in this workspace.
- Fonts: original Inter Variable, NType82 Headline and Ndot57 Aligned assets were copied without glyph modifications. Display/Headline and large-title roles now resolve through the device's system serif family (`FontFamily.Serif`) for Latin and Chinese; the retained NType82 asset is not selected by the default theme. Body text uses Inter with platform Chinese fallback; explicit dot displays retain Ndot57. File hashes are in [font-provenance.json](font-provenance.json). No system Chinese font is redistributed.
- Icons: original matching OTA dot vectors are retained, including the native three-circle more symbol. Settings supplies the seven-dot navigation arrow and nine-dot apps glyph, SystemUI the five-dot down arrow, Weather its 25-dot unslashed Wi-Fi, Camera its 31-dot camera, and Nothing X the 13-dot close and seven-dot lightning. Each official resource retains its original paths, dot positions, count, relative diameters and sparse/dense layout; no shared grid or dot radius is imposed. Only native small-icon sizing, fixed large-artwork family sizing and a mirrored back-arrow transform adapt them to existing slots. Unmatched confirmation uses MIT Pixelarticons native-cell derivatives (halfmage/pixelarticons commit c9ecc2da61afde85dbe539025e3d931c6152ad75). Original 2x2 cell centers become circles without coverage sampling; the unmatched confirmation uses 94% of the nearest diagonal-neighbor distance as diameter, retaining a fine 6% seam; Wi-Fi instead uses the original unslashed 25-dot Weather ic_main_no_connection; slashed disconnection variants are excluded. Originals, hashes and MIT license are in tools/vendor/pixelarticons and assets/licenses/Pixelarticons-MIT.txt.
- Other existing MDI derivatives: original source outlines use per-glyph regular matrices (9/10/11/12/13 columns per 24dp frame), one circle radius per glyph and diameter equal to 94% of pitch, leaving a fine 6% axial seam. Coverage selects filled bodies; source stroke guides retain thin structures. Original circles set grid phase. No freely positioned curve-following dots or manually drawn silhouettes. Circle construction reuses the upstream MIT converter. These are local third-party repairs, not original Nothing drawings or unchanged upstream release glyphs.
- Rendering: ordinary MDI pictograms retain fixed 25dp/em role sizing, add/remove symbols 22dp/em; per-glyph matrices retain their point positions, with dot diameter 94% of nearest-neighbor distance and a 6% seam. Native Pixelarticons retain their 24x24 author frame and fixed role scale. A bounded partial ink-centroid correction adjusts internal optical whitespace; slot layout never moves. No ordinary-icon fallback is used for known keys. Whole source fonts are not packaged.
- Third-party provenance: https://github.com/GeneralKaos666/ndot-firacode-nerd/tree/a2c370b24ba6f21a20bb50e42866ffb7345da99d . MDI artwork is Apache-2.0, source font OFL-1.1, upstream converter MIT. https://github.com/halfmage/pixelarticons/tree/c9ecc2da61afde85dbe539025e3d931c6152ad75 is MIT. Inputs, converter, recipes and hashes are retained in tools/vendor; notices are packaged in assets/licenses and transformations in [icon-provenance.json](icon-provenance.json).
- Coverage and fallbacks: [ICON_MAPPING.md](ICON_MAPPING.md).
