# Android 版本支持

minSdk 是 23（Android 6.0）。所有组件在每个版本上都能用；新系统效果完整，老系统按下表降级。

| Android | 效果 | 降级 |
|---|---|---|
| 13+（API 33） | 全部：融球着色器、组合振动。预测性返回在应用内跟手（14 起有系统动画） | — |
| 12 – 12L（31–32） | 屏幕物理圆角、动态取色、振动原语 | 融球走非着色器的画法 |
| 9 – 11（28–30） | 拇指投影用 `setShadowLayer` | 没有屏幕圆角：转场用 28dp 圆角；没有动态取色：固定种子色；振动用系统触感常量 |
| 6 – 8.1（23–27） | 所有组件和交互 | 拇指投影用几圈渐淡的胶囊叠出来；只有返回键；振动退回最基础的常量；示例 App 用圆形图标代替自适应图标 |

在 minSdk 23 下 lint 的 `NewApi` 检查是干净的。加了用到系统 API 的代码后跑一下 `./gradlew :mochi-compose:lintRelease`。
