# 提示

iOS 风格的顶部提示：像灵动岛长出来的胶囊（不做玻璃）。

```kotlin
val toast = rememberMochiToastState()
MochiToastHost(toast)                      // 页面根上放一个
toast.show("已拷贝", icon = { Icon(…) })
toast.show("AirPods Pro", subtitle = "已连接", onClick = { … })
```

- 从顶部中间的小「岛」柔和展开并落位，弹性克制、内容提前清晰；停留 `durationMillis`（默认 2.2 秒）后轻微收小、上移 18dp，在 190ms 内淡出，不再把文字挤回空胶囊
- 新提示替换旧的时，胶囊连续地变成新的大小，不会先收起再出来
- 内部内容替换保留 `MochiBlurText` / `MochiBlurCrossfade` 的模糊、缩放与淡入淡出，和整条提示的进出场独立。先测量新旧内容，再按内容变换进度计算占位；外层胶囊直接使用同一帧的内部尺寸，禁止对中间尺寸再启动一层追赶弹簧。副标题和图标的增加、移除及无图标时的留白也纳入尺寸过渡。复用同一图标 lambda 时不重复播放；图标依赖状态时捕获调用时的不可变值，让淡出的旧图标保持原来的样子。
- 按住：放大、发光、跟手（和按钮同一套），按住期间不会自动收起；往上甩收起，往下拉被橡皮筋拉住；轻点执行 `onClick` 并收起
- 出现时轻震一下
- 浮层只有胶囊接触摸，别处的点击照常落到页面上

配色：`MochiToastDefaults.colors()`，默认使用 MD3 inverseSurface 和增强对比度的 inverseOnSurface 前景。条件允许时标题达到 12:1 对比度，副标题使用前景色的 86% 不透明度；显式自定义配色仍按调用方设置。退场中收到新提示时，从当前透明度和位置恢复，不闪断、不重新从零弹出。

按压和跟手形变包住整张提示表面，圆角裁切、阴影、底色和内容一起变换；没有静止的外层胶囊把形变后的提示切出硬边。
